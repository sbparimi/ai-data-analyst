# Release Checklist

## Product
- [ ] Approved scope and release notes.
- [ ] All acceptance criteria verified.
- [ ] Known limitations disclosed.

## Correctness
- [ ] Golden numerical fixtures pass.
- [ ] Evidence provenance is complete.
- [ ] Dashboard/report values reconcile.
- [ ] AI abstention and grounding evaluations pass.

## Security and privacy
- [ ] Tenant-isolation matrix passes.
- [ ] Upload threat tests pass.
- [ ] Prompt-injection and tool-boundary tests pass.
- [ ] Secret and dependency scans reviewed.
- [ ] Retention/deletion behavior verified.
- [ ] No sensitive data in logs or test artifacts.

## Operations
- [ ] Monitoring and alerting verified.
- [ ] Backup/restore tested.
- [ ] Resource quotas and cost limits configured.
- [ ] Rollback plan tested.
- [ ] Runbooks current.

## Approval
- [ ] Staging verification accepted.
- [ ] Production deployment explicitly approved by owner.
- [ ] Release decision recorded with commit and evidence.
