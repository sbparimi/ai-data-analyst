# Architecture Decision Record

Create `docs/adr/NNNN-short-title.md` with:
- Status: Proposed / Accepted / Superseded / Rejected
- Date
- Context and verified constraints
- Decision
- Alternatives considered
- Evidence and official references with access date
- Security/privacy implications
- Cost/operational implications
- Consequences and migration plan
- Human approver when approval is required

Never mark a decision Accepted without the required owner approval.
